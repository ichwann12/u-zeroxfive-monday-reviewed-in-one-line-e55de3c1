One line, the funniest one-line review of my own Monday, under 200 characters:

> Monday gets one star: the coffee was cold, the meeting could have been an email, and the week has not even started.

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the line from `entry.txt` and writes it to the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), reading the repo root from `MAKEFUN_BOT_DIR` when set.
